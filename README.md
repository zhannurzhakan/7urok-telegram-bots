# Telegram-боты на Python

Три небольших бота. Только стандартная библиотека Python 3.9+, зависимостей нет.

| Файл | Что делает |
|---|---|
| `bot.py` | На любое сообщение отвечает временем, погодой в Астане ([Open-Meteo](https://open-meteo.com/)) и курсом биткойна ([CoinGecko](https://www.coingecko.com/)). |
| `checklist_bot.py` | Чек-лист: вечером принимает задачи на завтра, раскладывает по важности, части дня и темам, напоминает утром и перед задачами со временем. |
| `vacancy_bot.py` | Раз в день ищет вакансии по Казахстану по ключевым словам и присылает новые: с зарплатой, требуемым опытом и уровнем английского. Управляется кнопками. |

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Создайте файл `.env` по образцу `.env.example` и впишите токен:

   ```
   BOT_TOKEN=ваш_токен
   ```

   Файл `.env` в git не попадает (он в `.gitignore`). Никогда не публикуйте токен.
3. Запустите нужного бота:

   ```bash
   python3 vacancy_bot.py
   ```

Один токен может слушать только один запущенный бот. Если нужно запускать несколько ботов одновременно, создайте отдельные токены и укажите их в `.env`: `CHECKLIST_BOT_TOKEN`, `VACANCY_BOT_TOKEN`.

## Бот вакансий

- Источник: hh.kz. Официальный API hh требует регистрации приложения, поэтому бот читает открытую страницу поиска (данные лежат в JSON внутри HTML). Поиск идёт по всей РК, по названию вакансии, с паузой между запросами. Перед использованием убедитесь, что это соответствует правилам площадки.
- Ключевые слова добавляются, меняются и убираются кнопкой «🔑 Ключевые слова». По умолчанию: C&B manager, Менеджер по компенсациям и льготам, HR аналитика, Компенсации и льготы.
- Ежедневная подборка приходит в 09:00 по Астане (время меняется кнопкой). Подборка уходит только пока процесс запущен.
- Данные (подписчики, что уже отправлено) лежат в `vacancies.json`, он в git не попадает.
- Новые площадки добавляются классом с методами `search(query, days)` и `details(vacancy)` в список `SOURCES`.

## Данные и приватность

`.env`, `tasks.json` и `vacancies.json` содержат токен, идентификаторы чатов и личные задачи, поэтому исключены из git.
